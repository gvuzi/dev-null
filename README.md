## Features
- Projectile interception system predicting player movement using velocity calculations
- Shooting mechanics implemented with raycasting for hit detection
- Smooth player movement across FPS missions and an isometric hub environment
- Multiple enemy types: moving enemies actively tracking the player and stationary ranged enemies 
- Regenerative items that restore player health during gameplay
- Custom UI including a health bar, fragment tracker, pause menu, video and sound settings, and a main menu
- Interactive elements such as dialogue systems and scripted cutscenes
- Enhanced visuals with baked lighting, post-processing effects, custom 3D assets, and animations
